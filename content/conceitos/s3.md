## O problema que resolve

Armazenar objetos identificáveis e permitir sua publicação e consulta por operações de API.

## Como funciona

Amazon S3 significa Simple Storage Service. É um serviço de armazenamento de objetos; bucket e objeto são recursos e elementos utilizados dentro desse serviço.

### Bucket, objeto e chave
Um bucket armazena objetos e reúne configurações importantes de acesso e preservação. Um objeto reúne conteúdo e informações associadas. Sua chave identifica o objeto dentro do bucket.

| Elemento fictício | Exemplo |
|---|---|
| Bucket | `jardim-documentacao-estudo` |
| Chave do objeto | `portal/introducao.html` |
| Conteúdo | Bytes do HTML |
| Outra chave | `portal/imagens/logo.png` |

No modelo comum de buckets S3, a chave é o texto inteiro, incluindo as barras. O console apresenta prefixos como pastas para facilitar a navegação. Isso não transforma o bucket em um diretório comum do seu computador.

Com versionamento habilitado, a identificação de uma versão específica envolve também seu identificador de versão.

### Operações diferentes
Criar o bucket prepara o recipiente e suas configurações. Publicar documentação envia objetos. Consultar documentação busca objetos. As permissões dessas operações são diferentes.

Guardar HTML no S3 não significa executar uma aplicação de servidor. Os objetos podem compor um site estático ou ser consultados por uma aplicação. No cenário de armazenamento privado, o backend autorizado busca os arquivos para atender aos usuários.

Privado diz respeito ao acesso. Criptografado diz respeito à proteção criptográfica do conteúdo. Um arquivo pode ser público e continuar criptografado enquanto armazenado; o serviço o entrega de forma legível quando a leitura é permitida.

## No fluxo de entrega

Provisionar um bucket prepara o armazenamento; publicar envia objetos; ler busca seu conteúdo. Cada operação precisa das permissões adequadas.

## Exemplo

No bucket jardim-documentacao-estudo, portal/introducao.html é uma chave. Não é necessário criar outro bucket chamado portal para utilizá-la.

## Como verificar

Confirme o bucket e a chave corretos e teste publicação e consulta com as identidades previstas. A existência do bucket não comprova que os documentos foram enviados.
